Отлично! Для перевода приложения с китайского на русский с помощью RRO вам **не нужно** заморачиваться с файлом `res/xml/overlays.xml` (который я описывал для Android 11+). 

Для простой замены строк (перевода) достаточно **классического подхода** — создать ровно те же файлы `strings.xml`, но с русским текстом. Система сама подставит их вместо китайских.

Вот **пошаговая инструкция**, адаптированная именно под вашу задачу:

---

### Шаг 1. Узнайте пакет целевого приложения
Вам нужно точно знать имя пакета приложения, которое переводите. Обычно это `com.xxx.xxx`.
- Можно посмотреть в настройках телефона или выполнить:
  ```bash
  adb shell pm list packages | grep -i "название_фирмы"
  ```
  *Пример:* `com.alibaba.android` или `com.xiaomi.market`.

---

### Шаг 2. Создайте структуру папок RRO-проекта
Создайте на компьютере папку, например `MyRussianOverlay`, и внутри неё папку `res`.

```
MyRussianOverlay/
├── AndroidManifest.xml
├── res/
│   └── values-ru/            <-- ВНИМАНИЕ: папка именно values-ru!
│       └── strings.xml
```

**Почему `values-ru`?** 
В целевом приложении китайские строки лежат в папке `values-zh`. Чтобы их переопределить для русской локали, вы должны положить **точно такие же названия строк** в папку `values-ru`. Android поймет, что когда система запросит русский язык, нужно взять ваши строки.

---

### Шаг 3. Заполните файл `res/values-ru/strings.xml`
Откройте оригинальное приложение (например, декомпилируйте его или найдите в интернете его `strings.xml` из папки `values-zh`). Скопируйте **все названия** (ключи) строк, но вместо китайского текста напишите русский перевод.

*Пример:*  
Оригинал в целевом приложении (`res/values-zh/strings.xml`):
```xml
<resources>
    <string name="app_name">我的应用</string>
    <string name="button_ok">确定</string>
    <string name="menu_settings">设置</string>
</resources>
```

Ваш файл `res/values-ru/strings.xml`:
```xml
<resources>
    <string name="app_name">Моё приложение</string>
    <string name="button_ok">ОК</string>
    <string name="menu_settings">Настройки</string>
</resources>
```

---

### Шаг 4. Настройте `AndroidManifest.xml`
Это самый важный файл. Создайте его в корне папки:

```xml
<manifest xmlns:android="http://schemas.android.com/apk/res/android"
    package="com.yourcompany.translate.rro"> <!-- Любое уникальное имя вашего RRO -->

    <!-- Запрещаем иметь код (DEX) -->
    <application android:hasCode="false" />

    <!-- Объявляем, что это RRO для конкретного приложения -->
    <overlay
        android:targetPackage="com.example.target.app" <!-- СЮДА ВСТАВЬТЕ ПАКЕТ ПЕРЕВОДИМОГО ПРИЛОЖЕНИЯ -->
        android:priority="1" />
        <!-- targetName и resourcesMap для перевода строк не нужны, убираем их -->

</manifest>
```

---

### Шаг 5. Соберите APK
Так как у вас нет кода (чистые ресурсы), собрать можно даже без Android Studio, используя утилиту `aapt2` (она входит в состав Android SDK).

**Простой способ через командную строку:**

1. Скомпилируйте ресурсы:
   ```bash
   aapt2 compile -o compiled/ res/values-ru/strings.xml
   ```
2. Свяжите их в APK:
   ```bash
   aapt2 link -o MyTranslation.apk -I android.jar compiled/*.flat --manifest AndroidManifest.xml
   ```
   (Где `android.jar` — путь к вашей SDK-платформе).

**Или ещё проще:** Если у вас есть Android Studio, создайте пустой проект без Activity и просто скопируйте туда эту структуру. В `build.gradle` укажите `applicationId` как в манифесте и соберите APK.

---

### Шаг 6. Подпишите APK (обязательно!)
Система Android не установит неподписанный APK. Подпишите его отладочным ключом (можно через `apksigner` из SDK):
```bash
apksigner sign --ks debug.keystore MyTranslation.apk
```

---

### Шаг 7. Установите и активируйте
1. Установите APK на телефон:
   ```bash
   adb install MyTranslation.apk
   ```
2. **Включите оверлей** (он по умолчанию выключен):
   ```bash
   adb shell cmd overlay enable --user current com.yourcompany.translate.rro
   ```
3. Перезапустите целевое приложение (убейте его из памяти или перезапустите телефон) — строки должны стать русскими.

---

### Шаг 8. Если не работает (отладка)
Проверьте статус вашего оверлея:
```bash
adb shell cmd overlay list --user current | grep translate
```
- Если напротив вашего оверлея стоит `[x]` — он включен.
- Если стоит `---` — значит, не совпадают имена строк или он не видит целевой пакет.

Посмотрите логи на ошибки:
```bash
adb logcat | grep -i overlay
```

---

### ⚠️ Важное замечание для Android 11+
Если ваше целевое приложение имеет защиту через `<overlayable>` и требует указания `targetName`, тогда придется его добавить. Но **для 90% обычных приложений** (не системных) этой защиты нет, и классический способ с `values-ru` отлично работает.

---

### Итог
Для перевода вам нужны всего **2 файла**:
1. `AndroidManifest.xml` (с правильным `targetPackage`).
2. `res/values-ru/strings.xml` (с теми же ключами, что в китайской версии, но русскими значениями).

Никаких `overlays.xml`, цветов, размеров или кода — только чистая замена строк на нужном языке. Удачи! Если уточните пакет приложения, могу подсказать конкретнее.

Отличный вопрос! **Нет, автоматически не применятся**. После установки RRO-приложение находится в **неактивном** состоянии. Вам обязательно нужно выполнить дополнительные действия, чтобы оно заработало.

---

## 🔄 Что нужно сделать после установки:

### Способ 1. Через ADB (самый надежный)
После установки вашего APK выполните команду:
```bash
adb shell cmd overlay enable --user current com.yourcompany.translate.rro
```
Где `com.yourcompany.translate.rro` — это `package` из вашего `AndroidManifest.xml`.

**Чтобы проверить, включился ли:**
```bash
adb shell cmd overlay list --user current
```
В выводе напротив вашего RRO будет:
- `[x]` — **включен** (работает)
- `[ ]` — выключен
- `---` — ошибка (не видит целевое приложение или ресурсы)

---

### Способ 2. Через настройки системы (только для некоторых прошивок)
На чистых Android (AOSP) и некоторых прошивках есть пункт:
```
Настройки → Система → Для разработчиков → Разрешить переопределение ресурсов (или Overlays)
```
Но даже там обычно нужно найти ваше RRO в списке и включить переключатель. **На большинстве устройств этого пункта нет**, поэтому способ с ADB — универсальный.

---

### Способ 3. Установка в системный раздел (без активации)
Если вы поместите ваш APK в папку:
- `/vendor/overlay/` 
- или `/product/overlay/`

и перезагрузите телефон, то **RRO включится автоматически**. Но для этого нужны **root-права** и разблокированный загрузчик. Для обычного пользователя это не подходит.

---

## ❓ Почему не автоматически?
Система Android не включает RRO по умолчанию, потому что:
1. Оверлей может конфликтовать с другими.
2. Разработчик может установить несколько оверлеев для одного приложения и выбирать нужный вручную.
3. Это защита от случайных "поломок" интерфейса.

---

## 📋 Полный алгоритм для вашего перевода:
```bash
# 1. Установка
adb install MyTranslation.apk

# 2. Активация
adb shell cmd overlay enable --user current com.yourcompany.translate.rro

# 3. Перезапуск целевого приложения (убейте его из памяти или перезапустите телефон)
adb shell am force-stop com.example.target.app

# 4. Откройте приложение вручную — строки должны стать русскими
```

---

## 🧪 Как проверить, что перевод работает:
1. Откройте целевое приложение.
2. Переключите язык системы на русский (если он еще не установлен).
3. Если строки не изменились — проверьте статус:
   ```bash
   adb shell cmd overlay list --user current | grep translate
   ```
   Если видите `---`, значит:
   - Не совпадают имена строк в `strings.xml`
   - Неправильно указан `targetPackage` в манифесте
   - Приложение не имеет китайской локализации (строки могут лежать в `values/` без суффикса `-zh`)

---

## 🔄 Как отключить, если что-то пошло не так:
```bash
adb shell cmd overlay disable --user current com.yourcompany.translate.rro
```
И перезапустите целевое приложение — оно вернется к исходному китайскому языку.

---

## 💡 Совет для упрощения
Если вы делаете перевод для себя и не хотите каждый раз вводить ADB-команды, создайте **bat-скрипт (Windows)** или **sh-скрипт (Mac/Linux)**:

**enable_overlay.bat:**
```batch
adb shell cmd overlay enable --user current com.yourcompany.translate.rro
adb shell am force-stop com.example.target.app
echo "Оверлей включен, перезапустите приложение"
```

Теперь достаточно одного клика по файлу после установки.

---

**Итог:** Установка только "кладет" RRO в систему, но не активирует. Без команды `adb shell cmd overlay enable` перевод **не применится**. Выполните её один раз — и оверлей будет работать до перезагрузки телефона (и даже после, пока вы его не отключите).

Сделать так, чтобы RRO-оверлей не отображался в системе, можно, но для этого вам понадобятся **root-права**. Это связано с тем, что скрыть приложение из списка можно только в том случае, если оно установлено как системное .

Вот два основных способа:

### Способ 1: Установка как статичного RRO (идеальный вариант)

Это самый чистый метод. Оверлей становится частью системы и не отображается в списке установленных приложений.

1.  **Настройка манифеста**: В вашем `AndroidManifest.xml` нужно добавить атрибут `android:isStatic="true"`.
    ```xml
    <overlay
        android:targetPackage="com.example.target.app"
        android:isStatic="true"
        android:priority="1" />
    ```
    Статичные оверлеи включаются автоматически и не могут быть отключены пользователем. В официальной документации Android это описано как способ сделать оверлей неизменяемым .

2.  **Установка в системный раздел**: Готовый APK-файл нужно поместить в один из системных каталогов для оверлеев. Используйте для этого `adb` с root-правами:
    ```bash
    adb root
    adb remount
    adb shell mkdir -p /vendor/overlay/<your-overlay-name>
    adb push your-overlay.apk /vendor/overlay/<your-overlay-name>/
    adb reboot
    ```
    Вместо `/vendor/overlay` можно также использовать `/product/overlay` в зависимости от вашего устройства .

**Важно**: APK-файл должен быть подписан той же подписью, что и целевое приложение, или же (в некоторых случаях) системным ключом устройства .

### Почему обычная установка не работает?

Оверлей, установленный через `adb install`, становится обычным пользовательским приложением. Он всегда будет виден в списке установленных программ, и его можно будет удалить через настройки. Система видит его как динамический оверлей, которым можно управлять через `adb shell cmd overlay`, но скрыть его из интерфейса пользователя нельзя. В официальной документации Android указано, что динамические RRO доступны для управления через API или команды `adb` .

### Проверка и статусы

После установки и перезагрузки всегда полезно проверить статус оверлея.
```bash
adb shell cmd overlay list --user current
```
В выводе вы увидите статусы:
*   `[x]` — оверлей активен.
*   `[ ]` — установлен, но не активен.
*   `---` — установлен, но содержит ошибки (например, не найден целевой пакет) .

Вместе с `cmd overlay list` для диагностики ошибок удобно использовать команду `adb logcat | grep -i idmap` или проверить `mState` через `cmd overlay dump` .

Итог: **статическая установка в `/vendor/overlay` , чтобы ваш оверлей был невидим для пользователя и работал как системный компонент .
